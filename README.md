# Earshot

Earshot is a free podcast app for Android with over 19,000 podcasts built in, sorted by category: a speed for each show, skip the start, bookmarks, a queue, show notes with chapters, tidy downloads and Android Auto. No adverts in the app, no account.

Website: https://customgpter.github.io/earshot/
